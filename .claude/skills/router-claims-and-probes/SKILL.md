# Proving the Router's Own Claims

Fleet observability catches failures that **happen**. It cannot catch a capability that is silently **absent**, because absence emits no signal (`basecradle/basecradle#460`). Being the fleet's wake edge makes three of those classes ours: an agent can sit registered, healthy, and permanently unreachable; the NOC's freeze control can exist but be unreadable; a webhook sink can be armed on paper while every delivery is silently rejected. Each looks perfectly green. So the router **emits claims and records the evidence behind them** for the NOC's claims-vs-evidence ledger (`basecradle-noc#406`) — and, for the one claim that cannot be looked up, **proves it by running a probe**. *The router emits; the NOC judges — a component never grades its own homework.*

- **Evidence is written by the daemon, read by everyone else.** `evidence.EvidenceStore` records, per route, the deliveries that verified and were rejected, and per agent, the last `stage=wake outcome=ok` (timestamp + delivery id) plus ok/failed/**refused**/**deduped** counters. Refusals are kept apart from failures because a refusal is the converge lock or the breaker working, and an agent whose history is all refusals is *gated*, not unreachable; a **dedup** is kept apart from a refusal again because it is the one outcome only a *success* can produce — the cache is marked after a wake succeeds — so lumping it in made a healthy route's newest recorded attempt read as a rejection (#218, `basecradle-noc#462`). The counter is the classification: no consumer parses our reason strings. It lives at `/var/lib/basecradle-router/evidence.json` (**not** `/run`: an age-of-proof that reset every restart would report every proven capability as never-proven after a deploy), is written by atomic replace so an out-of-process reader never sees a torn document, and **degrades to memory with one warning if it cannot write**. The instrument must never be able to break the thing it instruments.
- **The claims are Contract v1** (`claims.py`), one manifest per subject: `wake-edge:webhook-route` per `agent:<slug>` — whose `detail.edges` is *what could wake it now* and whose `evidence` is *what demonstrably did* (`edge_count: 0` **plus** `evidence: null` is a parked builder with no re-wake path — neither half suffices alone); `wake-edge:webhook-route:<route>` per **armed** `(agent, route)` pair, the same question asked per *recipient*; `freeze-surface:readable` and `delivery-sink:<route>` per `box:<host>`. Whether an edge is armed is computed by pairing each enabled route's `Route.recipient_kind` with `Config.resolvable_by`, so **the emitter names no event source and adding a route never edits it** — the core/routes split holds here too.
- **A claim's `detail` is the flat projection of the sub-object its own evidence pointer names — or the claim is unarmable.** The NOC resolves a `<path>#<dotted.field>` pointer from the manifest the census carries, never by reading the file, under one rule: *the pointer's last segment is the field, and `detail` is the object it lives in* (`basecradle-noc#409`). A pointer that misses is refused by name and reads `unprovable` — loud, never green, and **never armed**, which is the same silence one level up. So the descriptive keys sit *beside* the evidence fields, never wrapped around them, and `test_every_declared_evidence_pointer_resolves_from_its_own_detail` re-runs the NOC's rule over every emitted claim.
- **An `evidence` claim cannot exercise itself, so the router gave it a lever** (`probe.py`, `routes/probe.py`). For an agent nobody happens to address, nothing ever proves the edge, and exercising an `evidence` claim only re-reads its pointer — so a healthy edge and a permanently dead one are indistinguishable, and the only remedy left is a *social* one. Shared law forbids exactly that: **a monitor never depends on a consent or trust surface**, and the system is never widened to make a monitor go green (`constitution.md` → Operational Baselines). The NOC's timeline-based prober is retired fleet-wide, @jt included (`basecradle-noc#421`). **We own the router→agent edge, so we prove it**: a signed test delivery fired at our *own* real verify→wake path, on-box over loopback, with no platform account and no relationship with anyone. Three properties make it honest, and each is structural rather than remembered — **token-free** (no code path can build a model command for a synthetic event; the wake-runner's `--probe` mode acks after the privilege drop without ever `exec`ing the model, and an agent with no `NOC_PROBE_SECRET` armed is a *refusal*, never a fallback); **unforgeable at the far end** (the marker is verified *as the agent*, against a file only that agent can read, so a pass means the wake reached that account with that account's credentials loaded — the router holds no agent's secret and verifies nothing); and **never a masquerade** (its own route tag, its own sinks, and a `synthetic` flag recorded beside every outcome *at write time*, since deriving it at read time would let a since-disabled route answer "real"). A probe is a **lever, never an edge**: it is excluded from `detail.edges`, because counting it would put `edge_count: 1` on a builder no event can reach and quietly retire the parked-builder finding — the instrument defeating itself.
- **The freeze self-test is a proof, not a lookup** (`selftest.py`). It reads the wake-lock surface through the daemon's own guard (via `WakeLockGuard.inspect`, the non-logging twin of `check`, so a read-only pass emits no `wake_refused` lines for wakes nobody attempted) and fails **naming the exact file**. Run it as the daemon's user — root bypasses file permissions, so a root run proves nothing and the probe says so. It runs at **boot, loudly, but never aborts startup**: the guard's fail-direction is to keep waking when a lock cannot be read, so a boot check that refused to start would invert that decision and turn a permissions typo into a fleet outage. **Fail-closed is the converge's job** (NOC Layer 1) — loud here, closed there.
- **A needle alarm's grammar is a claim about this repo's source, so the proof is ours too** (`log_grammar.py`). The NOC's extraction guard proves a derived column's regex against live traffic — but `breaker_tripped` matches a line that exists **only on the failure path**, so nothing arrives on a healthy fleet to watch and a rename like #228's would darken the *Circuit Breaker Tripped* alarm invisibly (`basecradle-noc#509`). `log-grammar:breaker_tripped` fires one: it drives a **real** `WakeRateBreaker` past its threshold so the daemon's own trip statement renders the bytes — **no second renderer**, so a rename in `breaker.py` moves the probe's bytes in the same commit — and writes them to the daemon's own journald identifier. Two discriminators keep it out of production alerting, and they are two because their consumers are: a trailing **`source=probe`** (the fleet's ratified wake-origin stamp, reused not re-minted) for the extraction-fed alarm, and **INFO instead of ERROR** for the severity-fed ones. A person gets a third cue: a leading bare **`PROBE`** (#315, the capital's ruling as amended on `basecradle-noc#857`), because the other two reach the eye last. All three ride **one** switch, so none can be set alone. `PROBE` leads and the stamp trails, so the genuine trip sits **whole between** the synthetic-only bytes: a re-point that matches the grammar matches a synthetic and a real trip alike. It proves **rendered**, and only that: the daemon is a uid-999 *system* user that structurally cannot read the journal back, so a read-back answered `unprovable` on a perfectly healthy box — and the repair is to narrow the claim, never to grant the wake-dispatching daemon `systemd-journal` so a check can go green (#234). **Landing** is the NOC's witness on our identifier and **extraction** its guard — a component never grades its own homework, here either.
- **One interface, one path:** `python -m basecradle_router {claims,selftest freeze,probe wake,probe log-grammar,evidence}`, wrapped on the box by `deploy/bin/router-admin` (privilege drop + env). The CLI is strictly **read-only** — a probe run under the wrong identity must never take the evidence file's ownership away from the daemon (`probe log-grammar`'s one journal line is its only side effect, and it touches no router state). That rule is also what gives `probe wake` its integrity: it reports `proven` only because the *daemon* recorded a wake carrying the delivery id this run minted, so the probe cannot manufacture its own pass (*"the probe's own PASS is not the proof; `last_ok_at` moving is"*). Exit codes, TTLs, and the on-box invocation: `deploy/README.md` → "Proving what the router claims."
